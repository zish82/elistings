A · Mac: key and first login

1Create the SSH key

Enter for the default place, then a passphrase.

ssh-keygen -t ed25519
2Change the expired root password

Hetzner's password first, then the current one again, then a new one twice. Save the new one.

ssh root@2.29.130.158
3Copy the key to the server

Uses the new root password once. Should end with "Number of key(s) added: 1".

ssh-copy-id root@2.29.130.158

B · Hetzner Console: firewall

4Find your home IP
curl -4 ifconfig.me
5Create and apply the firewall

Firewalls → Create firewall. Inbound: TCP 22 from YOUR_HOME_IP/32; TCP 80 and 443 from Any; ICMP from Any. Apply it to the server.

C · Server (as root): your own user

6Create user zee with sudo and your key

adduser asks a password (for sudo), then name, room number, phones – press Enter to skip those, then Y.

adduser zee
usermod -aG sudo zee
rsync --archive --chown=zee:zee ~/.ssh /home/zee
7Test the new login in a new Mac terminal

Don't continue until this works – step 9 turns off root and password logins.

ssh zee@2.29.130.158

D · Server (as zee): secure it

8Updates, automatic security updates, fail2ban

Answer Yes in the last one.

sudo apt update && sudo apt -y upgrade
sudo apt -y install unattended-upgrades fail2ban
sudo dpkg-reconfigure -plow unattended-upgrades
9SSH: keys only, no root login
sudo tee /etc/ssh/sshd_config.d/00-hardening.conf >/dev/null <<'EOF'
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no
EOF
sudo systemctl restart ssh
10Swap, timezone, reboot
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
sudo timedatectl set-timezone Europe/London
sudo reboot

E · Docker

11Install Docker
ssh zee@2.29.130.158

21Nightly database backup

Run the first line, then paste the second into the editor that opens.
